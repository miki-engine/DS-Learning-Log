SQL Intermediate Practice

Overview

This project contains four intermediate SQL exercises using user, product, and order data.

The exercises cover joining multiple tables, aggregating data, using subqueries, checking for the existence of related records, and organizing queries with a Common Table Expression (CTE).

What I practiced

* Joining tables with INNER JOIN
* Joining multiple tables using related keys
* Grouping data with GROUP BY
* Calculating totals with SUM()
* Counting rows with COUNT()
* Sorting aggregated results with ORDER BY
* Using subqueries with IN
* Finding records with no related data using NOT EXISTS
* Using SELECT 1 with EXISTS / NOT EXISTS
* Creating a Common Table Expression (CTE) with WITH
* Using table aliases to make queries more readable

What I learned

I learned how to combine data from multiple related tables and calculate aggregated values such as the total amount spent by each user.

I also learned how subqueries can be used inside conditions such as IN and NOT EXISTS, and how NOT EXISTS can be used to find users who do not have matching records in another table.

In addition, I learned how to use a CTE with WITH to define an intermediate result set and then use that result in another query. This can make complex SQL queries easier to organize and understand.

Future improvements

* Practice more complex subqueries and correlated subqueries
* Practice using multiple CTEs in a single query
* Learn how to use window functions such as ROW_NUMBER(), RANK(), and SUM() OVER()

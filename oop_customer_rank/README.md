# Customer Rank Management Practice

## Overview
This script creates customer objects from master data, adds purchase amounts from action logs, and assigns each customer a rank based on total purchase amount.

## What I practiced
- Defining a Python class
- Creating instances from master data
- Managing objects with a dictionary
- Updating object attributes with methods
- Using `if __name__ == "__main__"`
- Writing a `.py` script instead of a Jupyter Notebook

## What I learned
In Jupyter Notebook, I can test code step by step using cells.
In a `.py` file, I need to organize the program so that it can run from top to bottom.

I also learned that a dictionary is useful for finding a customer object by `customer_id`.

# SQL Basic Practice

## Overview

This scripts are basic SQL plactices.

## What I practiced

* Narrowing down with `WHERE`
* Sorting data with `ORDER BY`
* Grouping data with `GROUP BY`
* Counting the number of data with `COUNT`
* Calculating the average with `AVG`
* Calculating the total for each category with `SUM`
* Refining conditions after grouping with `HAVING`
* Branching conditionally with `CASE`


## What I learned

I learned basic SQL syntax.

I also learned `WHERE` is filtering original data before grouping, and `HAVING` is filtering results after grouping and aggregating them.

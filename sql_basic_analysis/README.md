# SQL Basic Practice

## Overview

This project contains four basic SQL exercises using user and order data.

The exercises cover filtering, sorting, grouping, aggregation, filtering aggregated results, and conditional classification.

## What I practiced

* Filtering data with `WHERE`
* Sorting data with `ORDER BY`
* Grouping data with `GROUP BY`
* Counting rows with `COUNT()`
* Calculating averages with `AVG()`
* Calculating totals for each user with `SUM()`
* Filtering aggregated results with `HAVING`
* Creating conditional categories with `CASE`

## What I learned

I learned the basic syntax of SQL and how to use filtering, grouping, and aggregate functions to extract and summarize data.

I also learned that `WHERE` filters rows before grouping, while `HAVING` filters the aggregated results after `GROUP BY`.
